# 돋보기 공장

1억 5천만 개 대신 1,728개? — 합성곱 신경망(CNN)을 손으로 체험하는 앱입니다. 완전 연결과 합성곱 첫 층의 가중치 비교, 이미지를 한 줄로 펴면 멀어지는 이웃, 칸을 눌러 바꾸는 그림 위로 필터를 한 칸씩 훑는 합성곱(원고의 [0, 27, 27] 예 포함), 패딩·스트라이드 출력 크기 계산기, 위치가 조금 바뀌어도 그대로인 최대 풀링, 사진 크기와 상관없는 가중치 공유, 필터 깊이와 채널, 층층이 쌓는 CNN, 드롭아웃과 데이터 증강, VGG의 3×3 두 번과 ResNet 지름길, 끌어 보는 IoU, 문턱을 바꾸는 비전 검사 라인까지 담았습니다. 지능 09 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 합성곱: 가중치 수 사건, 펴면 멀어지는 이웃, 합성곱 놀이터(그림·필터 선택, 한 칸씩 훑기)
- ② 크기·풀링: 출력 크기 계산기와 그림, 퀴즈 ①(14), 최대·평균 풀링
- ③ 가중치: 가중치 공유 계산기, 필터 깊이와 채널, 퀴즈 ②(448)
- ④ 깊게·검사: CNN 구조, 드롭아웃·증강, VGG·ResNet, IoU, 비전 검사 라인, 코드, 세 줄 정리, 생각해 볼 질문
