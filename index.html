🖼️ 사건 접수: 첫 층의 가중치 수

224 × 224 컬러 사진 한 장 = 숫자 150,528개. 첫 층 두 가지를 비교합니다.

완전 연결(뉴런 1,000개)이면 첫 층 가중치만 150,528,000개. 합성곱 첫 층은 1,728개로 시작합니다 — 약 8만 7천분의 1. 비밀은 ③ 가중치에서!

🏗️ 층층이 쌓는 CNN

합성곱 → ReLU → 풀링을 반복하며 앞쪽은 선·모서리, 중간은 무늬·부분, 뒤쪽은 큰 형태를 찾습니다. 작아진 특징 맵을 그제야 펴서 분류기에 넣고 소프트맥스로 확률을 냅니다. 앞부분 = 보는 눈(특징 추출부), 뒷부분 = 판단하는 머리(분류기).

🛡️ 외우지 않게: 드롭아웃과 데이터 증강

증강
드롭아웃: 몇 명이 빠져도 일이 돌아가는 팀처럼 특정 뉴런에 기대지 않게. 증강: 컨베이어 위 각도와 조명은 매번 다르니, 같은 불량도 다양한 모습으로 보여 줍니다(가상 제품 그림).

import torch.nn as nn nn.Conv2d(3, 64, kernel_size=3, padding=1) # 3×3×3×64 = 1,728 (+편향 64) nn.Conv2d(3, 16, kernel_size=3) # 432 + 16 = 448 nn.MaxPool2d(2) # 4×4 → 2×2 nn.Dropout(0.5) nn.Linear(150528, 1000) # 150,528,000 (+편향 1,000) # 출력 크기 = (N − K + 2P) // S + 1 → (28 − 3 + 2) // 2 + 1 = 14

📌 세 줄 정리

  1. 이미지를 펴지 않고 작은 필터로 훑어 특징 맵을 만든다.
  2. 패딩·스트라이드로 크기를, 풀링으로 핵심을 정하고, 필터를 돌려 써서 가중치를 아낀다.
  3. 드롭아웃과 증강으로 외우기를 막고, ResNet의 지름길과 전이 학습으로 깊고 똑똑하게 배운다.
